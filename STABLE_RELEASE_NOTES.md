Blocksy is a multiplayer block-building game for the web and the Nintendo 3DS (homebrew), with shared worlds, chat and friends.

## What's new since 1.2.0

### Changes
- Network fixes: 3DS updater tuned like Iker's Tube, and web fallback when the STORE server does not answer (create game and shop).
- Clear error when STORE is unavailable while creating or editing games.
- 3DS updater matches Iker's Tube: automatic stable install, release notes summary, show devbuilds setting.
- 3DS now draws all 12 hats and loads the full hat catalog.
- Studio: rotate, flip and move block selections; multi-select parts with Shift+click.
- Studio: lock and hide parts, explorer search and rename, align and distribute parts.
- Studio: grid, measure tool, bookmarks, Ctrl+D, Ctrl+A and a shortcuts sheet.
- Script editor: snippets, autocomplete, find and replace, and a console with error line links.
- Studio versions with restore, draft mode and a last-saved indicator.
- Studio: terrain brush, water fill, torches and lamps, time of day slider and Dawn sky.
- Studio: own structure library, structure import and export, game thumbnails and a compact toolbar.
- Command palette, g-shortcuts, offline banner and retry on failed page loads.
- Home: continue playing card, friends playing now, streak and daily reward, and a random game button.
- Discover: search suggestions, trending, similar games and report a game.
- Profile: bio counter, banner color, share profile and friend nicknames.
- Friends filters and search, do not disturb, per-type notification settings and day separators in chats.
- Chat tabs, timestamps, @mentions and a searchable chat history (F2).
- Saved places, copy coordinates, stamina bar and per-player voice volume.
- Screenshot gallery, report from the player list, in-game clock and player list sorting.
- Shop filters and sorting, purchase history and a better avatar preview.
- Settings: search, collapsible sections, per-section reset and export/import.

## Installing
- Install `Blocksy.cia` with FBI, or copy `Blocksy.3dsx` to the `3ds` folder of the SD card and run it from the Homebrew Launcher.
