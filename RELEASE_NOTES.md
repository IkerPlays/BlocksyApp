Nintendo 3DS: your account is now remembered. Tick Keep me signed in on the login screen and the app signs in by itself next time (only a renewable token is saved on the SD card, never the password). The login also renews itself while you play.
Nintendo 3DS: gameplay improvements. Run with B, climb one-block steps automatically, C-stick camera on New models, the block you are about to place or break is outlined, player names float over their heads, chat shows on screen, sky and distance fog, smoother camera, and movement now follows real time so it feels the same at any frame rate. D-pad left and right change the block color.
Nintendo 3DS: fixed the game page showing the menu text on top of it. Creating games is removed from the 3DS (it is a web-only feature of the owner account).
Web: fixed the [object HTMLDivElement] text on Home, removed all emojis (new line icons), better 3D rendering (textured blocks, shadows, sky, animated avatars, block outline, camera that does not go through walls), on-screen controls for tablets and phones, run with Shift and automatic steps. Create is only visible to the authorized account and is enforced on the server.
Updates: the app reads releases from RELEASES_REPO when the main repository is private (see the README).
