Devbuild 63: real-time collaboration in the Studio
- New Collaborate button in the Studio ribbon. The owner starts a session and shares the link (studio/<id>?join=CODE). Other people open it and edit the same game at the same time.
- Synced live: parts (move, create, delete), the game script, and who has what selected (colored boxes and name chips). Blocks follow the game's normal building rules.
- The owner's Studio is the source of truth and the only one that saves (Save button and the automatic save every minute). Guests cannot save; if the owner closes the Studio their changes are lost.
- The session code is part of the live channel name, so only people with the link can join. Environment and game settings are not synced.
